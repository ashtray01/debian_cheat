🐧 Debian Knowledge Base — Dev & Deploy

⚠️ Наличие sudo зависит от способа установки Debian: при отключённом root-пароле первый пользователь обычно получает sudo, иначе используйте su - или установите sudo: apt update && apt install sudo && usermod -aG sudo ИМЯ_ПОЛЬЗОВАТЕЛЯ (затем перелогин). Если sudo уже настроен, sudo -i открывает полноценную login-shell root с домашним каталогом /root; для разовой операции безопаснее и прозрачнее использовать sudo команда.
